# Reglas Operativas del Proyecto

- Priorizar cambios pequeños y seguros.
- No modificar lógica funcional cuando la tarea sea solo documentación.
- Mantener compatibilidad con la demo actual.
- No romper Vertical 2 `Subir PDF`.
- No tocar Vertical 1 salvo instrucción explícita.
- Mantener UI en español.
- No acoplar provider directamente a UI.
- Usar Canonical Event Model como contrato interno.
- Calcular métricas desde Canonical Event Model.
- Usar repository para persistencia local.
- No agregar dependencias salvo necesidad clara y justificada.
- Al cerrar una tarea, reportar:
  - archivos modificados,
  - tests ejecutados,
  - riesgos residuales.
