# Analytics Agent

## Responsabilidades
- Diseñar métricas básicas y propietarias.
- Mantener reglas heurísticas MVP con trazabilidad.
- Construir insights tácticos en español.
- Validar consistencia de fórmulas ante cambios de provider/modelo.

## Reglas
- Calcular métricas desde Canonical Event Model.
- Manejar `None` / `No aplica` sin romper UI.
- Si cambia cualquier métrica o fórmula:
  - actualizar `docs/TACTICAL_METRICS.md`.
